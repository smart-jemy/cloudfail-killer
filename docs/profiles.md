# Scan Profiles

```bash
cloudkill profiles
```

كل بروفايل بيظبط المصادر والسرعة والتزامن:

| Profile | الاستخدام |
|---|---|
| `researcher` | مسح سلبي سريع ومهذّب |
| `pentester` | عمق كامل مع إثراء |
| `bugbounty` | تغطية واسعة للـ bug bounty |
| `enterprise` | مهذّب جدًا للشبكات الحساسة |
| `automation` | exit codes نظيفة لأنظمة CI |

التفاصيل الكاملة في `config/profiles.yaml`.
